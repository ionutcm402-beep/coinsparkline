# Phase 3 — Global Product Shell

Phase 3 standardises CoinSparkLine's shared product chrome before further page redesign.

## Locked shell rules

- Header uses one restrained navigation language across desktop and mobile.
- Mobile navigation is provided by the header drawer; the legacy fixed mobile dock is no longer mounted globally.
- Global decorative flowing-line background is removed from the root shell.
- Search, currency and account controls share the same compact interaction language.
- Footer uses quiet surfaces and consistent product/research/trust grouping.
- Route-level loading uses a neutral skeleton rather than decorative animation.
- Recoverable route errors use one consistent message and retry action.
- Keyboard and accessibility state are treated as first-class shell behaviour.

## Phase boundary

This phase does not redesign the homepage or migrate every product page. Existing page content may still contain legacy page-level styles until its scheduled phase. The shared shell should no longer introduce a competing visual generation.
